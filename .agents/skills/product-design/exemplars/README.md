# Exemplars

Exemplars document **successful decisions worth repeating**. They are not a
component gallery and not a license to copy flaws.

Each exemplar should identify:

- Relevant surface
- User problem
- Decision
- Why it worked
- Evidence (files)
- Reusable principle
- Known flaws that should **not** be copied

Use an exemplar when the current job matches its surface and principle. Check
the flaws list before cloning the implementation.

Do not manufacture positive examples when evidence is weak. Prefer a coverage
gap over a fake win.
